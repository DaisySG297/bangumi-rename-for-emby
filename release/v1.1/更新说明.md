## 怎么用

1. 把 EXE 放进番剧所在目录（脚本会**递归**处理所有子文件夹）。
2. 双击运行 → 程序列出预览（旧名 / 新名）→ 输入 `y` 回车执行，输入其他字符取消。
3. 只改文件名，不改内容、不移动位置；目标名已存在时自动跳过，不覆盖。

输出统一为 `标题 - SXXEXX - 发布组.ext`，适配 Emby 刮削。

## 本版（v1.1）改了什么

1. **支持外站英文点分（scene）发布名**
   `标题.S01E02.1080p.WEB-DL.DUAL.AAC2.0.H.264.MSubs-发布组.ext` 这类名字以前会报「未在当前目录及子文件夹中找到可识别的文件」，现在可以直接识别。
   原因：老版本只认开头的 `[发布组]` 方括号，外站命名把组名放在结尾，第一步就被判为无法识别。
   规则：集号只认 `SxxExx` / `Exx` 段（不认裸数字，避免把 264 / 1080 当集号）；末段技法前缀（`MSubs-`、`BluRay-`、`264-`）自动剥离；末段只是 `1080p` / `x264` / `chs` 之类标签时视为没有发布组，输出省略末段；`Erai-raws`、`Nix-Raws`、`DBD-Raws` 等真实带横杠的组名原样保留。

2. **修掉一个会导致「一个文件都没改」的崩溃**
   工作区里同时存在能识别与不能识别的文件时，程序在打印提示行时抛 `UnicodeEncodeError`（GBK 编不出 `⚠️`），确认后实际一个都没改。现已把输出流的错误策略改为替换，顺带让文件名里的 `½` `♪` `☆` 等字符也不再引发崩溃。

3. 新增解析引擎单测 `tests/test_extract_info.py`（24 项），抽出 `build_filename()` 统一拼接输出名。

> 旧版能处理的名字，本版结果完全一致，可放心替换。
