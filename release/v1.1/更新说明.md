## 怎么选

- **命令行版**：放进番剧目录双击，程序列出「旧名 → 新名」预览，输入 `y` 回车执行，输入其他字符取消。适合塞进脚本、qBittorrent「下载完成时运行外部程序」等自动化链路。
- **图形界面版**：同样的解析与输出逻辑，但提供可视化界面 —— 选目录、扫描预览表格、逐行勾选、右键手动修正单条结果、导出 CSV、一键撤销。适合日常手动整理、想先看清楚再动手的场景。

两版输出结果**逐字节一致**（界面版直接复用命令行版的核心解析函数），换用任意一版都不会出现命名差异。

## 命令行版怎么用

1. 把 EXE 放进番剧所在目录（脚本会**递归**处理所有子文件夹）。
2. 双击运行 → 程序列出预览（旧名 / 新名）→ 输入 `y` 回车执行，输入其他字符取消。
3. 只改文件名，不改内容、不移动位置；目标名已存在时自动跳过，不覆盖。

输出统一为 `标题 - SXXEXX - 发布组.ext`，适配 Emby 刮削。

## 图形界面版怎么用

1. 双击 EXE 打开窗口（无控制台黑框）。
2. 「选择目录」指定番剧所在文件夹；可勾选是否递归子目录、是否同步处理字幕。
3. 按 `F5` 扫描 → 预览表格列出「状态色标 / 原文件名 / 重命名结果 / 所在子目录」。
4. 单击任意行切换勾选（默认全选），可全选 / 全不选 / 反选；右键单条可手工指定新文件名。
5. 按 `Ctrl+Enter` 执行重命名。每次执行自动把记录写入 **EXE 所在目录**的 `rename_history/`，随时可「一键撤销」完整还原。

快捷键：`Ctrl+O` 选择目录、`F5` 扫描、`Ctrl+Enter` 执行。

## 本版（v1.1）改了什么

1. **支持外站英文点分（scene）发布名**
   `标题.S01E02.1080p.WEB-DL.DUAL.AAC2.0.H.264.MSubs-发布组.ext` 这类名字以前会报「未在当前目录及子文件夹中找到可识别的文件」，现在可以直接识别。
   原因：老版本只认开头的 `[发布组]` 方括号，外站命名把组名放在结尾，第一步就被判为无法识别。
   规则：集号只认 `SxxExx` / `Exx` 段（不认裸数字，避免把 264 / 1080 当集号）；末段技法前缀（`MSubs-`、`BluRay-`、`264-`）自动剥离；末段只是 `1080p` / `x264` / `chs` 之类标签时视为没有发布组，输出省略末段；`Erai-raws`、`Nix-Raws`、`DBD-Raws` 等真实带横杠的组名原样保留。

2. **修掉一个会导致「一个文件都没改」的崩溃**
   工作区里同时存在能识别与不能识别的文件时，程序在打印提示行时抛 `UnicodeEncodeError`（GBK 编不出 `⚠️`），确认后实际一个都没改。现已把输出流的错误策略改为替换，顺带让文件名里的 `½` `♪` `☆` 等字符也不再引发崩溃。

3. **首次发布图形界面版 EXE**（本次新增 `番剧批量重命名(界面版).exe`）
   界面源码与命令行版共用同一套解析 / 输出函数，因此两版结果一致；界面版额外支持预览勾选、手动修正、导出 CSV 与一键撤销。

4. 新增解析引擎单测 `tests/test_extract_info.py`（24 项），抽出 `build_filename()` 统一拼接输出名。

> 旧版能处理的名字，本版结果完全一致，可放心替换。

- 进程退出码 `0`，结论「自检结果：全部通过」。

## 想自己打包

```bash
pip install pyinstaller

# 命令行版
pyinstaller --onefile --name "番剧批量重命名(字幕版)" bangumi_rename.py

# 图形界面版（必须使用自带 tkinter 的 Python）
pyinstaller --onefile --windowed --name "番剧批量重命名(界面版)" ^
  --hidden-import bangumi_rename bangumi_rename_gui.py
```
